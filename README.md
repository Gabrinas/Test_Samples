The audios generated by the spectrogram-based and discrete-based audio generations experiments are contained in this repository.
The spectrogram-based audio generation uses spectrogram plus audio pair fed as input to an HiFi-GAN vocoder.
For the discrete-based audio generation, three different discrete unit models were experimented with: (1) HuBERT (2) wav2vec 2.0 and (3) WavLM.
Each of their discrete units plus audio pair were fed as input to a unit HiFi-GAN vocoder.
All the experiments carried out involved fine-tuning the respective vocoders starting with the pretrained checkpoints.
